# Backend Service

## Environment

Set the following variables before starting the API:

- `PORT`
- `CORS_ORIGIN`
- `DB_HOST`
- `DB_PORT`
- `DB_USER`
- `DB_PASSWORD`
- `DB_NAME`
- `JWT_SECRET`
- `JWT_EXPIRES_IN`

## Commands

- `npm run dev` – local development with reload
- `npm start` – production mode
